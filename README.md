# Digital Drawing Assist 🎨

A floating overlay Android app to help you trace images easily.

## ✨ Features
- 📷 Select image from gallery
- 🖼 Overlay on screen
- ✋ Drag / Move
- 🔍 Pinch Zoom
- 🔄 Rotate
- 🎚 Transparency control
- 🧠 Floating control panel
